# 果价地图

Apple 全球硬件价格比较网站原型。产品目录采用 Apple 官网购买链接白名单，包含 30 个当前在售硬件/基准配置、12 个市场、含税价/游客退税后价切换、货币换算、搜索、排序与分享链接。

产品白名单于 2026-06-22 按 Apple 美国官方商店购买页核对。每个产品对象都必须包含 `u`（Apple 官网链接）；官网不再提供购买入口时，应在每日更新中移除。

## 本地运行

```powershell
node server.mjs
```

浏览器打开 `http://127.0.0.1:4173`。

## 数据说明

当前版本为完整交互原型：产品基准价、市场调价系数、税率、退税比例及演示汇率位于 `app.js`，会在页面中明确标注为估算信息。生产部署时应把这些字段替换为服务端每日任务产生的版本化 JSON：

1. 每日抓取各地区 Apple 官方商店公开售价，并记录 SKU、配置和抓取时间。
2. 从可靠汇率 API 固定时点获取汇率。
3. 对税率/游客退税规则建立人工审核表，不直接用自动抓取结果覆盖。
4. 每次任务进行异常波动检测，通过后原子替换线上数据；失败则保留上一版。

建议使用 GitHub Actions 或 Cloudflare Cron Trigger 每天运行一次更新任务。Apple 页面结构和地区条款可能变化，生产使用前需确认抓取合规性。
